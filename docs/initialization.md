## 组件与平台能力

|能力|接入方式|实测结论|
|---|---|---|
|按钮|uview-plus，`KbButton` 薄封装|点击和关闭预览可操作|
|输入|uview-plus `up-input`|空值提示、输入与返回保留通过|
|开关|uview-plus `up-switch`|默认开启；关闭后弹层不含答案节点|
|弹层|uview-plus `up-popup`|初始隐藏、打开、动画后可见和关闭通过；补齐 `u--` / `u-` / `up-` easycom 以支持内部依赖|
|文件|Web 原生 input + File/Blob|uni 通用 input 不提供 file 类型，因此适配层用 Vue render 创建原生输入；错误文件签名拒绝、选择和移除通过|
|PDF / 图片|Web iframe / img + 对象URL|PDF iframe、图片预览、原字节下载通过；支持依浏览器能力而定，未承诺手机 Safari/真机兼容|
|路由和会话|uni 路由 + Pinia + 注入式内存会话|页面往返保留本次配置；刷新清空；业务身份尚未接入|
|API|类型化客户端 + uni.request 适配|环境可切换地址；缺配置拒绝请求；HTTP与业务成功分开判断；未声明任何新业务接口|

## 本轮验证

`npm ci` 后运行 lint、strict 类型检查、5项核心测试、Web生产构建及 Chromium 生产页面验证。浏览器验证覆盖1280×900及390×844，含答案红色、学生答案移除、输入/开关/弹层、返回状态、无效文件、PDF下载字节一致、图片预览、刷新清空、无横向溢出和无运行错误。手机尺寸是浏览器视口验证，未做真机验收。

现有管理端 `npm run build:prod` 已通过；5173入口仍可读取。新预览只监听127.0.0.1:5193，没有切换后端、数据库或管理端进程。
